# Local open-source SVG icons

These small outline SVGs are original, locally bundled adaptations in a Lucide-style line-icon system. They are released for reuse under the ISC licence. The Lucide project is also open source under ISC: https://lucide.dev/icons/ and https://github.com/lucide-icons/lucide/blob/main/LICENSE.

The assets are stored in the repository and served locally—no paid library, icon font or external icon CDN is required. Content-card icons are decorative and use empty alt attributes because the adjacent headings explain each card.
